# Adaptive-mesh treecode for Hartree potential evaluation

This repository contains the implementation and numerical evidence for
**“A Treecode Algorithm for Hartree Potential Evaluation on Locally Refined
Meshes.”**

Start with the curated reproducibility artifact:

- [Code, tests, data, and manuscript source](errorControl/paper_artifact/README.md)
- [Active working directory](errorControl/)
- [Fixed `arxiv-v1` release](https://github.com/XiaoHuanzzz/treecode/releases/tag/arxiv-v1)

The `arxiv-v1` tag records the exact source associated with the manuscript.
Large generated meshes and common-target files are provided as release assets
rather than stored in ordinary Git history.

No open-source license has yet been selected by all authors. Normal copyright
restrictions therefore remain in force; contact the corresponding author before
reuse or redistribution beyond verification of the reported results.
